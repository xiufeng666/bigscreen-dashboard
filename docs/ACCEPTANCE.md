## 3. 六平台构建产物

`scripts/build-all.sh` 在离线环境交叉编译（`CGO_ENABLED=0`、`-trimpath`、静态链接）：

| 目标平台 | 产物 | `file` 校验 |
|---|---|---|
| Windows x86_64 | `bigscreen-server_windows_amd64.exe` | PE32+ executable x86-64 |
| Windows x86（32 位） | `bigscreen-server_windows_386.exe` | PE32 executable Intel 80386 |
| macOS Apple 芯片 | `bigscreen-server_darwin_arm64` | Mach-O 64-bit arm64 |
| macOS Intel | `bigscreen-server_darwin_amd64` | Mach-O 64-bit x86_64 |
| 银河麒麟 / 统信 UOS x86 | `bigscreen-server_linux_amd64` | ELF x86-64 statically linked |
| 银河麒麟 ARM（飞腾/鲲鹏） | `bigscreen-server_linux_arm64` | ELF ARM aarch64 statically linked |

- macOS arm64 发行二进制已拷贝到空目录独立启动验证：页面、主题 CSS、三套示例图片、编辑器均正常返回，数据目录自动创建。
- Linux 产物为**完全静态链接**，不依赖 glibc 版本，适配银河麒麟 V10、统信 UOS 20 等国产系统；启动脚本按 `uname -m` 自动选择对应二进制。
- Windows 提供 64 位与 32 位两个版本，均为控制台程序，双击 `start.bat` 即可启动并自动打开浏览器。

## 4. 离线与安全核验

- 页面请求仅指向本机服务：自动化测试监听 `Network.requestWillBeSent`，**0 个外部请求**；无 CDN、无外链字体、无网络图标库。
- 前端资源（HTML/CSS/JS/SVG）全部 `go:embed` 进二进制，部署时只拷一个可执行文件即可。
- 用户内容统一使用 `textContent`/DOM 属性渲染；图片上传做扩展名白名单 + 文件头魔数校验 + 随机文件名；静态文件服务防路径穿越。
- 可选密码鉴权：HMAC-SHA256 签名 Cookie（HttpOnly/SameSite=Lax），服务重启自动失效。

## 5. 已知边界与建议

1. **多编辑器并发**：采用 rev 乐观锁，后保存者会收到 409 冲突弹窗（载入最新 / 覆盖保存），不支持多人实时协同编辑；单管理员场景不受影响。
2. **服务端无展示端时暂停轮播计时**：这是设计行为，方便上墙前编辑；打开任意大屏后继续计时。
3. **控制条悬浮 UI** 在鼠标移动时显示、3 秒后隐藏；正式上墙建议使用 `?kiosk=1` + 浏览器 F11 全屏。
4. 目标浏览器为 Chromium 内核 90+（Chrome/Edge/360 极速/奇安信/UOS 浏览器）及 Firefox 90+；未针对 IE 与老版内核浏览器适配。
5. `?scene=N` 使用 0 基索引（与 `runtime.scene` 一致）。
6. 大屏页面通过 SSE 长连接实时刷新；在 Nginx 反代后需关闭 `/api/events` 缓冲（README 已给出配置）。
